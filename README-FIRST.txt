Welcome to the Demo Edition of Raphael AI!
Raphael is an intelligent local desktop companion with real-time web search,
system vitals monitoring, voice feedback, and a glowing visual HUD.

------------------------------------------------------------------------
STEP 0 (IMPORTANT - If you received this as a .zip):
------------------------------------------------------------------------
Before extracting:
1. Right-click the zip file -> Properties.
2. At the bottom, check the "Unblock" checkbox (if present) -> click OK.
3. Extract the folder.

------------------------------------------------------------------------
STEP 1: QUICK SETUP
------------------------------------------------------------------------
1. Make sure you have Ollama installed for local AI conversations:
   Download free at: https://ollama.com
   Open PowerShell/CMD and type:
       ollama run qwen2.5:3b

2. Double-click "setup_demo.bat".
   This will verify Python 3.10+, install required lightweight packages,
   and create a "Raphael Demo" shortcut on your Desktop.

------------------------------------------------------------------------
STEP 2: RUNNING RAPHAEL
------------------------------------------------------------------------
Double-click the "Raphael Demo" shortcut on your Desktop, or run "run_demo.bat".

------------------------------------------------------------------------
DEMO EDITION SAFETY GUARDRAILS:
------------------------------------------------------------------------
For your protection on this computer:
- Command-line execution (CMD / PowerShell / Python) is strictly disabled.
- Screen capture, mouse automation, and computer control are disabled.
- System cleaners and Recycle Bin emptying are disabled.
- File operations are strictly jailed inside the "demo_sandbox" folder.
- No network ports are exposed to other devices on your Wi-Fi.

Enjoy exploring Raphael AI!
